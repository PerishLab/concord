# Concord v0.12.6

## Task 名字陈述「做完之后什么会成立」

此前没有任何地方写过名字该承载什么，于是名字取自最容易写出来的东西：促成这条线的那个发现、
正在碰的那个工具、或即将开始的那件事。这样的名字**不约束任何东西**，工作会长过它，
而其他 Task 与已冻结 Phase 里的每一处散文引用仍指向它。

随版本发布的 skill 现在写明：**名字陈述这条 Task 做完之后什么会成立**。
没有终态的常驻线改为陈述自己的职能 —— 那对这种形状是正确的，对其余每一种都是错的。

新增一条 restrained scenario 覆盖最要紧的情形：**当交付目标尚不足以命名时，上报并停下**。
事后改名保留永久 identity，但会让先前的引用指向一个不再存在的名字，
**而那正是本 estate 被审计的第一类漂移**。词汇归调用方所有。

Keel lock 推进到 0.10.4。
